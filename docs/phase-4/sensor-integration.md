# Phase 4 Sensor Integration & Signal Conditioning Specification
## Smart Water Tank Monitoring System — Transducers, Calibration & Protection

**Document Reference**: `docs/phase-4/sensor-integration.md`  
**Target Hardware**: NodeMCU v2 (ESP8266), HC-SR04, ZJ-S201 / YF-S201, ACS712-05B  
**Status**: IMPLEMENTED AND VERIFIED VIA COMPILED SUITES & BENCH FORMULAS

## 1. Executive Summary

The Smart Water Tank Monitoring System relies on three primary physical transducers and reserves one extension interface:
1. **HC-SR04 Ultrasonic Level Sensor**: Non-contact acoustic time-of-flight measurement with tank geometry calibration, 5-sample running median filtering, and freshness tracking.
2. **ZJ-S201 / YF-S201 Turbine Water Flow Sensor**: Hall-effect pulse counting via interrupt service routine with flow-rate computation, volume integration, and a 60 LPM plausibility ceiling.
3. **ACS712ELCTR-05B-T Current Sensor**: Hall-effect analog current sensing conditioned via an external precision resistor divider ($K_{div} = 0.642857$), zero-current calibration, and RMS sampling.
4. **Water Leakage Sensor (Extension)**: Reserved driver interface, cleanly disabled pending physical hardware selection and pin assignment.

## 2. HC-SR04 Ultrasonic Water-Level Sensor Integration

### 2.1 Electrical Interface & Conditioning
- **Supply Voltage**: $5.0\,\text{V}$ DC (Acoustic transducers require 5V for sufficient sonic power).
- **Trigger Pin (D1 / GPIO5)**: Driven directly by ESP8266 3.3V logic. The HC-SR04 trigger circuit accepts CMOS logic thresholds ($V_{IH} \ge 2.0\,\text{V}$).
- **Echo Pin (D2 / GPIO4)**: The sensor produces a 5.0V pulse. To prevent damage to the 3.3V ESP8266 input, an external voltage divider is installed:
  $$V_{GPIO4} = 5.0\,\text{V} \times \frac{2.0\,\text{k}\Omega}{1.0\,\text{k}\Omega + 2.0\,\text{k}\Omega} = 3.33\,\text{V}$$

### 2.2 Measurement Math & Tank Geometry Calibration
Acoustic time-of-flight equation ($c = 343\,\text{m/s} = 0.0343\,\text{cm/\mu s}$):
$$\text{Distance to Water Surface } D\,(\text{cm}) = \frac{t_{echo}\,(\mu\text{s}) \times 0.0343\,\text{cm/\mu s}}{2}$$

The level percentage is computed against configurable tank geometry:
$$\text{Water Height in Tank } H_{water} = D_{empty} - D$$
$$\text{Water Level Percentage } P = \left(\frac{D_{empty} - D}{D_{empty} - D_{full}}\right) \times 100\%$$

- **Default Parameters**:
  - $D_{empty} = 100.0\,\text{cm}$ (Sensor to tank bottom when empty).
  - $D_{full} = 15.0\,\text{cm}$ (Sensor to maximum fill waterline).
  - Minimum valid distance: $2.0\,\text{cm}$ (Transducer dead zone).
  - Maximum valid distance: $400.0\,\text{cm}$ (Acoustic timeout limit).

### 2.3 Noise Filtering & Freshness Protection
- **Median Filter**: A 5-sample circular buffer computes the running median of distance readings, effectively rejecting surface ripples, condensation spikes, and false reflections.
- **Freshness Gate (`isStale`)**: Every valid pulse records `_lastMeasureTimeMs = millis()`. If the controller does not receive a fresh acoustic reading within **5000 ms**, `isStale(now, 5000)` trips true, forcing the pump controller into `SENSOR_ERROR` and de-energizing the relay.

## 3. ZJ-S201 / YF-S201 Water Flow Sensor Integration

### 3.1 Electrical Interface & Conditioning
- **Supply Voltage**: $5.0\,\text{V}$ DC.
- **Output**: 5V periodic square wave generated by an internal Hall element.
- **Level Shifting**: Pin `D5` (`GPIO14`) is protected by an identical $1.0\,\text{k}\Omega / 2.0\,\text{k}\Omega$ voltage divider, delivering clean $3.33\,\text{V}$ pulses to the ESP8266 interrupt line.

### 3.2 Safe Interrupt-Driven Counting
```cpp
// Static ISR executed in IRAM for high-speed deterministic capture
void IRAM_ATTR FlowSensor::handleInterrupt() {
  uint32_t now = micros();
  // Hardware de-bounce: reject pulses closer than 2000 microseconds (> 500 Hz)
  if (now - _lastInterruptMicros > 2000) {
    _pulseCount++;
    _lastInterruptMicros = now;
  }
}
```

### 3.3 Flow-Rate & Volume Formulas
- **Nominal Flow Factor**: $f\,(\text{Hz}) = 7.5 \times Q\,(\text{L/min})$
- **Nominal Pulses per Litre**: $K = 7.5 \times 60 = \mathbf{450 \text{ pulses/L}}$
- **Flow Rate Calculation**:
  $$Q\,(\text{L/min}) = \frac{\Delta\text{pulses} \times 1000}{\Delta t\,(\text{ms})} \times \frac{60}{K_{pulses\_per\_litre}}$$
- **Plausibility Ceiling**: For standard 1/2-inch residential plumbing, flow rates exceeding **60.0 L/min** are physically implausible. If $Q > 60.0\,\text{L/min}$, `_isPlausible` is flagged false to prevent corrupted telemetry.
- **Cumulative Usage**:
  $$\text{Total Water Used } (\text{Litres}) = \frac{\text{Total Pulses Accumulated}}{K_{pulses\_per\_litre}}$$

### 3.4 Wet Calibration Procedure
1. Place a calibrated 10.0-Litre volumetric container under the pump discharge pipe.
2. Energize pump and fill exactly to the 10.0L mark.
3. Record pulse count $N_{pulses}$ from serial diagnostics.
4. Calculate calibrated constant: $K_{cal} = \frac{N_{pulses}}{10.0}$.
5. Apply via `flowSensor.setCalibration(K_cal)`.

## 4. ACS712 Current Sensor Conditioning (`HW-002`)

### 4.1 Electrical Characteristics & The Saturation Problem
- **Module**: Allegro ACS712ELCTR-05B-T (5A bidirectional variant).
- **Sensitivity**: $185\,\text{mV/A}$ ($0.185\,\text{V/A}$).
- **Quiescent Output ($I = 0\text{A}$)**: $V_{IOUT(Q)} = \frac{V_{CC}}{2} = 2.50\,\text{V}$.
- **NodeMCU Limitation**: The NodeMCU A0 pin accepts a maximum input voltage of **3.30V**. Without conditioning, motor startup surges ($>3.425\,\text{V}$) saturate the ADC at 1023 counts, causing severe non-linear clipping.

### 4.2 Signal Conditioning Circuit
A precision passive voltage divider scales the $0.0\,\text{V} - 5.0\,\text{V}$ sensor output into the $0.0\,\text{V} - 3.21\,\text{V}$ range:

```
ACS712 Vout (0 to 5.0V)
      |
     [ ] R_ext1 = 10.0 kΩ (1% Metal Film)
      |
      +----------> NodeMCU A0 Pin (0 to 3.21V Max)
      |
     [ ] R_ext2 = 18.0 kΩ (1% Metal Film)
      |
     GND
```

$$\text{Divider Attenuation Ratio } K_{div} = \frac{R_{ext2}}{R_{ext1} + R_{ext2}} = \frac{18.0}{10.0 + 18.0} = \frac{18}{28} \approx \mathbf{0.642857}$$

| Parameter | Sensor Voltage | Voltage at A0 ($K_{div} = 0.642857$) | ADC Count (0–1023) |
| :--- | :---: | :---: | :---: |
| **$I = 0\,\text{A}$ (Quiescent)** | $2.500\,\text{V}$ | $1.607\,\text{V}$ | 498 counts |
| **$I = +2\,\text{A}$ (Normal Pump)** | $2.870\,\text{V}$ | $1.845\,\text{V}$ | 572 counts |
| **$I = +5\,\text{A}$ (Rated Full Load)**| $3.425\,\text{V}$ | $2.202\,\text{V}$ | 682 counts |
| **$I = +8\,\text{A}$ (Motor Stall Peak)** | $3.980\,\text{V}$ | $2.558\,\text{V}$ | 793 counts |
| **$5.00\,\text{V}$ Rail Fault** | $5.000\,\text{V}$ | $3.214\,\text{V}$ | 996 counts ($\le 1023$) |

### 4.3 Conversion Equations
In `CurrentSensor.cpp`:
$$V_{A0}\,(\text{mV}) = \frac{\text{rawAdc}}{1023} \times 3300.0\,\text{mV}$$
$$V_{sensor}\,(\text{mV}) = \frac{V_{A0}}{K_{div}} = V_{A0} \times \frac{28}{18} = V_{A0} \times 1.55556$$
$$I\,(\text{Amperes}) = \frac{|V_{sensor} - V_{quiescent\_calibrated}|}{185.0\,\text{mV/A}}$$

- **Noise Deadband**: Current measurements below **0.08 A** are gated to zero to filter minor ambient ADC jitter.
- **Motor Active Verification**: `currentSensor.isMotorCurrentDetected(0.2f)` confirms whether pump motor current ($\ge 0.2\,\text{A}$) is physically drawing power through the relay contacts.

## 5. Water Leakage Sensor Interface (`LeakageSensor.h`)

Per Phase 4 Non-Negotiable Rules, no fabricated hardware is permitted:
- **Status**: UNCONFIRMED / NOT CONNECTED.
- **Driver State**: Cleanly disabled class (`isEnabled() == false`, `isLeakDetected() == false`).
- **Reporting**: Reports `"DISABLED_NOT_INSTALLED"` in status queries.
- **Pin Reservation**: Left unallocated to prevent conflicts with boot strapping pins.
